이 저장소는 MATLAB과 Simulink로 바이콥터의 자세 제어를 배우는 한국어 실습 자료입니다. 실험 데이터로 선형 모델을 식별하고, PID 제어기를 설계·튜닝한 뒤 디지털 트윈에서 성능을 확인하고 실제 Arduino 기반 하드웨어에 적용하는 과정을 다룹니다. 실습 스크립트, Simulink 모델, 측정 데이터와 3D 모델 파일이 포함되어 있습니다.
